# Product Details (PDP) Specification

1. **Purpose**: Showcase multi-angle studio and lifestyle photography alongside variant selection, sizing, accordion details, gifting banner, recommendations, and customer reviews.
2. **Route**: `/products/[slug]`
3. **Components**: `ProductDetailView`, `ProductCard`, `RecentlyViewedSection`, `ReviewsSection`.
4. **Interactive Features**:
   - 7-tile 2-column gallery with click-to-zoom Lightbox Modal.
   - Live finish swatch and ring size switching that updates displayed studio imagery, price, and stock status.
   - Expandable `Product Details`, `Shipping & Returns`, and `Material` accordions.
   - Interactive `Size Guide` modal.

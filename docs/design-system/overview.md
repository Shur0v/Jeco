# Design System Overview

The **J&CO. Jewellery** design system implements a **Luxury Minimalist E-Commerce / Editorial Jewellery Commerce** aesthetic characterized by generous white space, crisp 1px `#EAE6E4` borders, `#F6F6F6` studio product backdrops, `#E7A7AA` dusty rose primary CTAs, and `#FADADD` blush editorial surfaces.

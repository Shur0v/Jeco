# Reusable Components Reference

- **`ProductCard` (`src/components/shared/ProductCard.tsx`)**: Universal product card supporting square studio artwork, hover angle swap, finish swatch switching, quick-add bag icon, wishlist heart toggle, and subtle status badges.
- **`AnnouncementBar` (`src/components/layout/AnnouncementBar.tsx`)**: Full-width `#292929` rotating promotional banner.
- **`Header` (`src/components/layout/Header.tsx`)**: Sticky navigation header with brand wordmark, single-line category navigation, currency dropdown, search button, account link, and cart drawer badge.
- **`MegaMenu` (`src/components/navigation/MegaMenu.tsx`)**: Desktop flyout menu supporting the `Shop` and `14K Gold` multi-column layouts.
- **`MobileNavDrawer` (`src/components/navigation/MobileNavDrawer.tsx`)**: Responsive slide-out drawer for mobile and tablet viewports.
- **`Footer` (`src/components/layout/Footer.tsx`)**: Signature `#FADADD` blush pink footer with Help, Showroom, About, and `JOIN US JEWELS` newsletter subscription.
- **`ToastContainer` (`src/components/shared/ToastContainer.tsx`)**: Accessible `aria-live="polite"` feedback toast.
